# Password Generator

A React application that generates secure, customizable passwords quickly and conveniently.

## Features

- Generate random passwords instantly
- Choose the password length
- Include or exclude uppercase letters, lowercase letters, numbers, and symbols
- Copy the generated password to the clipboard
- Simple, responsive user interface

## Getting Started

### Prerequisites

- Node.js 14 or later
- npm or a compatible package manager

### Installation

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Install the dependencies:

	```bash
	npm install
	```

4. Start the development server:

	```bash
	npm run dev
	```

5. Open the local URL shown in the terminal.

## Usage

1. Select the desired password length.
2. Choose the character types to include.
3. Generate a password.
4. Use the copy action to copy it to your clipboard.

## Available Scripts

- `npm start` — runs the app in development mode
- `npm test` — runs the test suite
- `npm run build` — creates a production build

## Technologies

- React
- JavaScript
- HTML and CSS

## Security Note

Use generated passwords for individual accounts and store them in a trusted password manager. Do not reuse passwords across services.
